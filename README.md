

\# Unity Object Placement Editor



Unity 3D 道具擺放編輯器



\## Project Overview



本專案使用 Unity 與 C# 開發，

實作一套 3D 場景道具擺放系統。



使用者可以透過右側道具清單，

拖曳不同形狀的 3D 道具，

並將其放置於具有高低起伏的曲面場景中。



\## Features



\- 3D Terrain：具有不同高低起伏的曲面

\- Object Selection：可展開的道具選單

\- Drag and Drop：拖曳道具至場景

\- Placement Preview：即時放置預覽

\- Raycast Detection：曲面射線偵測

\- Object Interaction：物件選取與刪除

\- Guide Line：道具放置指引線

\- Responsive UI：響應式介面
